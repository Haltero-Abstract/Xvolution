XVOLUTION — éditeur de carte

16 à 40 colonnes (au-delà de 16 : défilement horizontal dans le jeu, cadre jaune = écran 320 x 240). On ajoute / retire des colonnes à droite.
On ajoute / retire des lignes en haut (fin du niveau) : le départ reste en bas.

Tuiles (clic gauche = peindre)

Composants (clic = poser)

Clic droit : enlève le composant sous la souris (sinon remet la tuile « carte »).
Maj + glisser : rectangle de la tuile choisie.
Pistes : choisir « auto » puis glisser : les coudes se font tout seuls.
Double-clic sur un composant : nom écrit dessus (68030, TOS_ROM… ; _ = espace) ; * devant le nom = BOSS (cadre rouge).
